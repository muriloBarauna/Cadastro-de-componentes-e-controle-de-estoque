# Cadastro-de-componentes-e-controle-de-estoque
Para colocar em pratica meu conhecimento e desenvolvimento sobre a linguagem python, decidi desenvolver esse projeto basico que me permite adicionar componentes eletronicos a uma lista e também visualizar a lista com todos os componentes presentes. Com esse projeto pude colocar em pratica a aplicação de (Listas, tuplas e dicionários, Manipulação de textos, Leitura e escrita de arquivos, Arquivos CSV e conceitos básicos de JSON e Tratamento de erros com try e except).
